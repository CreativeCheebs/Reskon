# Change log

What changed in each version of Reskon, newest first, in plain words. Versions before 0.6.6 are described in the git history (each has a commit called "Version x.y.z: ...").

## 0.6.6 (20 Nov 2026)

**New**

- Board cards can show priority and level as symbols only, without their names. Turn it on per board in **Card** settings → "Symbols only". Point at a symbol to see its name.

**Fixed**

- Sessions: the coloured day totals next to the date, and the tags in the Tags and Subtypes columns, no longer touch each other.
- Filter bars (Sessions and boards): when the filters wrap onto a second line, that line no longer starts with a stray divider or an indent.
- Quick capture: the text box shows one focus ring that fits it, and the hint under it has room above it.
- Hidden-status lists (Cancelled, Backlog and so on): the Title column keeps a usable width. A narrow window scrolls sideways instead of squeezing the title into one letter per line.
