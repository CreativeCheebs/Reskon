# Change log

What changed in each version of Reskon, newest first: one line per change, in plain words. Versions before 0.6.6 are in the git history (commits called "Version x.y.z: ...").

## 0.6.6 (20 Nov 2026)

- New: board cards can show priority and level as symbols only (Card settings → "Symbols only").
- Fixed: Sessions day totals, tags and subtypes no longer touch each other.
- Fixed: filter bars no longer start a wrapped line with a stray divider or indent.
- Fixed: quick capture shows one focus ring that fits the box, with room above the hint.
- Fixed: hidden-status lists (Cancelled, Backlog…) keep a readable Title column and scroll sideways when narrow.
